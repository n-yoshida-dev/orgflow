# ADR-010: 同一承認段は誰か1人の承認で完了する

- Status: Accepted
- Date: 2026-03-24
- 関連: ADR-009（承認段と承認者の構造） / ADR-004（状態遷移）

> **決定**: 同一承認段に複数の承認者がいる場合、誰か1人が承認すればその段は完了する。全員承認が必要な場合は承認段を分けて表現する。主担当・副担当の区別は持たない。

## 背景

1つの承認段に複数の承認者が存在するケースを Phase 1 でも扱えるようにした（ADR-009）。しかし、同一段の完了条件を決めないと、状態遷移、承認処理、テストの方針がいずれも定まらない。

完了条件の候補は、全員承認、主担当制、誰か1人で完了の3つがあった。

## 理由

- 完了条件が1つに固定されるため、状態遷移のロジックに分岐が入らない
- 「その段の承認者のうち1人が承認したら次の段へ進む」という単純な規則で、承認処理とテストが書ける
- 全員承認が必要なケースは、承認段を分けて順番に承認させることで表現できる。データ構造を変えずに対応できる

## 検討した他の案

- **案A: 同一段の全員承認を必須にする** — 誰が承認済みで誰が未承認かという段の途中状態を持つ必要があり、状態管理が複雑になる
- **案B: 主担当と副担当を持つ** — 役割の定義が増え、主担当が不在のときの扱いなど追加ルールが必要になる
- **案C: ケースごとに完了条件を切り替える** — 柔軟だが、段ごとに完了条件を持つことになり、設計・実装・テストがまとめて重くなる

## 受け入れる制約

- 全員承認が必要なユースケースを、段を分けずに直接表現することはできない
- 主担当・副担当のような役割の差を扱えない
- 順序を問わない全員承認（並列合議）は表現できない

## 見直す条件

- 全員承認を段を分けずにデータで表現する必要が生じた場合
- 主担当・副担当や代理承認を設計対象に含める場合
- 承認制度の複雑化により、単一の完了条件では業務要件を満たせなくなった場合
